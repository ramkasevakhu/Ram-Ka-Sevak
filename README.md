# 🏹 राम का सेवक (Ram Ka Sevak)
### सेवा ही भक्ति है • ramkasevak.org

> **"भूखों को अन्नदान, मूक जीवों की रक्षा व असहायों का सहारा"**  
> Official humanitarian ground seva platform lead by **Vipu (@vipuone)**.

---

## 🌟 4 Core Seva Projects (पावन सेवा प्रकल्प)

1. **अन्नदान एवं सड़क सहायता (Annadaan & Street Food Seva)**: Fresh, nutritious, hygienic 4-roti, sabzi, dal-chawal hot meal thalis distributed to roadside homeless people and elders.
2. **मूक जीव एवं गौ सेवा (Jeev Daya & Animal Rescue)**: Feeding street dogs fresh milk, boiled eggs, and protein food; fresh green fodder, bran, and jaggery for sacred cows; emergency first aid for wounded animals.
3. **आपातकालीन चिकित्सा सहायता (Emergency Hospital & Patient Support)**: Direct financial aid for poor patients struggling with emergency doctor consultation, prescription medicines, lab tests, and hospital bed charges.
4. **प्राकृतिक आपदा राहत कोष (Disaster Emergency Relief)**: Emergency dry ration kits, waterproof roof tarpaulins (tripal), and clean drinking water for families hit by floods, earthquakes, or natural crises.

## 🛠️ Tech Stack

- **Frontend**: Next.js 14 (App Router), React, Tailwind CSS, Lucide Icons
- **Database / Backend**: Supabase (PostgreSQL with RLS policies)
- **Deployment**: Vercel & GitHub
- **Payments**: Direct Universal UPI (PhonePe, Google Pay, Paytm, BHIM) with 0% platform fee + dynamic QR generation

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/ramkasevakhu/Ram-Ka-Sevak.git

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
